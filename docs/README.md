本目录是项目的长期知识库，供开发者、维护者和 AI Agent 查询。开始修改代码前，
先从这里定位相关文档；若文档与实现不一致，以代码、配置和测试为准，并在同一次
变更中修正文档。

## 项目背景

WeCom DM Sync 是基于
[`wecom-cli`](https://github.com/WecomTeam/wecom-cli) 的本地企微私聊同步与客服管理
应用。FastAPI 后端将企微联系人和近期开启的私聊同步到 SQLite，Vue 3 前端提供账号、
聊天、黑名单、设置和日志页面，Electron 可在开发环境中统一管理前后端进程。

系统使用轮询而非服务端推送，因此提供的是“接近实时”的本地缓存。每个客服账号由
独立的 worker 子进程同步，以隔离凭据和故障。除手动文本回复外，系统还支持可选的
AI 自动回复，以及“客户新发送图片或视频后自动加入黑名单”的业务策略。

## 能力边界

- 当前只同步私聊，历史窗口受企微与 `wecom-cli` 限制，通常约 7 天。
- 当前只发送文本，不支持主动发送图片、文件或贴纸。
- 在本应用中读取消息不会清除企微客户端的未读状态。
- AI 自动回复依赖外部 HTTP 服务，默认地址为 `http://localhost:8080/chat`。
- 音视频转码依赖可选的 `ffmpeg` 和 `ffprobe`。
- Electron 安装包目前不是自包含产物，运行环境仍需安装 Python、`uv` 和 `wecom-cli`。
